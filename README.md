# smartgrid-serverless-iot-pipeline
End-to-end serverless IoT data pipeline built on AWS using Amazon SQS, AWS Lambda, DynamoDB, Amazon S3, AWS Glue, Amazon Athena, EventBridge, SNS, and CloudWatch.

## Overview

This project demonstrates the implementation of a scalable serverless IoT data pipeline on Amazon Web Services (AWS). The solution processes real-time industrial sensor data, detects anomalies, stores enriched records in a data lake, and sends automated alerts using an event-driven architecture.

## Architecture

- Amazon SQS
- AWS Lambda
- Amazon DynamoDB
- Amazon S3 Data Lake
- AWS Glue
- Amazon Athena
- Amazon EventBridge
- Amazon SNS
- Amazon CloudWatch
- IAM

## Features

- Real-time sensor data ingestion
- Serverless event-driven processing
- Automated anomaly detection
- Data lake storage on Amazon S3
- SQL analytics using Amazon Athena
- Email alert notifications using SNS
- Infrastructure monitoring with CloudWatch
- Cost-optimized serverless architecture
